# Weevcrafts logo concepts

Open [index.html](index.html) to compare ten original logo directions. The gallery lets you switch surfaces, change preview size, save favorites, and download any SVG. [contact-sheet.png](contact-sheet.png) is a static overview.

| Number | Concept | Idea |
| --- | --- | --- |
| 01 | Woven W | Textile monogram within a soft square |
| 02 | Petal Wheel | Handmade warmth and community |
| 03 | Maker's Seal | Craftsmanship and confidence |
| 04 | Endless Thread | A flowing making process |
| 05 | Artisan Arch | A welcoming craft marketplace |
| 06 | Patchwork | Diverse products and makers |
| 07 | Sprout Loom | Growth from patient craft |
| 08 | Craft Compass | Discovery of distinctive pieces |
| 09 | Stitch Script | A maker's embroidered signature |
| 10 | Unity Knot | Makers and customers connected |

The SVGs have transparent backgrounds and outlined lettering. No external assets or installed fonts are required to use them. They contain small hover animations; reduced-motion settings disable those transitions. `build.py` is the editable source and needs `fonttools` to regenerate the SVGs.

These are design concepts. The current application logo remains in use until a concept is selected. A selected mark can then be adapted for the header, favicon, and role portals. Before commercial use, check the selected design against relevant trademark registers.
