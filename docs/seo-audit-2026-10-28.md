# Search indexing audit — 28 October 2026

## Evidence

Search Console's report, last updated 23 October, showed 18 indexed and 49
excluded URLs. Live URL Inspection separately confirmed the homepage is on
Google and indexed on 28 October. A public HTTP crawl found all 37 URLs in the
hosted sitemap return 200 with indexable metadata and matching canonical URLs.
This verifies technical eligibility, not ranking.

This report records the pre-deployment findings and local verification. Hosted
release checks and Search Console validation follow deployment.

| Report | Finding and outcome |
| --- | --- |
| Noindex: 11 | Public size-guide, privacy, terms, sustainability and press pages had unintended exclusions. They are now indexable in code, along with published information pages. Our-story/FAQ examples were older crawls and are already indexable live. Private accounts and previews remain excluded. |
| 404: 8 | Old storefront URLs. Four relevant permanent redirects are implemented below. Removed items without equivalent replacements retain genuine 404s. |
| Robots blocked: 1 | `/cart/update` is a private operation and should remain blocked. |
| Redirect: 1 | Exclusion is expected for redirected URLs. Existing canonical-host redirects are retained. |
| Discovered: 18 | Current catalog/category URLs await Google's crawl. They are server-rendered and linked; the sitemap now includes public information pages too. |
| Crawled: 10 | Includes `/products`, `/makers`, `/brands/korean-white`, www/http aliases, retired product URLs and old Atom feeds. Contextual collection metadata is improved; existing canonical-host redirects remain. |

Exact redirects checked by regression tests:

| Previous URL | Replacement |
| --- | --- |
| `/pages/about-us` | `/about` |
| `/collections/frontpage` | `/products` |
| `/collections/arts-collection` | `/categories/arts` |
| `/collections/sarees` | `/categories/textiles` |

The remaining 404 examples are `/collections/handmade-bangles`,
`/collections/home-made-pickles`, `/collections/warli-painting` and
`/products/saree`. The current catalog establishes no equivalent replacement for
those exact items. A genuine 404 is an appropriate removal signal.

Additional corrections:

- Sitemap URLs come from the published storefront revision and visible content
  pages, including `/pages/returns`. Hidden pages are omitted. Database failure
  returns a retryable 503 instead of a partial sitemap.
- Legacy `/pages/` aliases canonicalize to the built-in public route.
- Paginated catalog pages retain their page number in canonical URLs.
- Pages without an editorial description use visible page content. Saved
  editorial metadata takes precedence.
- Categories, makers and brands receive contextual metadata; unknown brands
  return 404 instead of an empty success page.
- Existing homepage brand title, canonical URL, supplied logo and linked
  WebSite/Organization structured data were verified and preserved.

## Verification and release follow-through

Go SEO regression checks and the opt-in Playwright sitemap/redirect test passed.
Every URL in the fixture's updated sitemap returned 200 with matching canonical
and `index,follow` metadata. Browser checks covered 390px and 1440px layouts.

After an authorized deployment:

1. Repeat the checks on the hosted sitemap, metadata, redirects and www/http
   aliases; confirm Search Console fetches the sitemap successfully.
2. Request recrawls of the homepage and corrected public pages, then validate
   public noindex fixes. Private exclusions and removed URLs may remain in reports.
3. Recheck URL Inspection after Google recrawls; reports do not update instantly.
4. Improve real product descriptions, maker profiles and external brand
   references. The live catalog contains a QA-labelled maker and short
   descriptions; these require accurate business content, not invented claims.

First place for “weevcrafts” cannot be guaranteed. The homepage is indexed;
ranking also depends on content and external signals.
