# Release preflight — 17 October 2026

Scope: previously verified seller, customer, guided storefront and selected-item
checkout changes, followed by the brand-search discovery repair.

## Search discovery

The canonical root domain is accessible with HTTP-to-HTTPS redirection, index/follow,
consistent brand title/description, WebSite and Organization identity, robots.txt
and an XML sitemap. The previous deployment already supplied the brand title.
The retrieved search result still showed the old homepage title; exact Google
indexing and ranking remain unverified without connected Search Console access.

Fixed missing maker sitemap entries caused by querying a nonexistent seller slug.
Sitemap paths now share the customer renderer's maker convention, use active seller
visibility and category relationships, and return retryable 503 on query failure.
Cleaned duplicate aliases and linked the website publisher to its organization.
A fallback homepage sharing image uses the existing logo. No visible redesign or
manufactured business/social details are included.

The owner confirmed the Search Console property is verified. Browser integration
is disabled and no Search Console connector is available in this session, so the
operator must request indexing and resubmit the sitemap using
[the documented follow-up](../seo-search-discovery.md). Search ranking is not a
code-level acceptance claim. The optional www alias still requires DNS ownership.

## Data protection

Production PostgreSQL was exported with pg_dump custom format and its PGDMP header
verified. The dump stays outside Git under the operator's local application-data
release-backup directory. It was restored successfully to a separate local QA
PostgreSQL database and migrated from version 49 to 50 transactionally.

Whole-row fingerprints remained identical for users, roles, sellers, products,
variants, inventory, orders/items, carts/items and storefront drafts after excluding
only the new additive cart fields. All 35 existing carts became shopping carts;
no records or quantities were removed. The source snapshot contained 15 users,
3 sellers, 19 products, 18 orders and 20 order items. This backup is sensitive and
must not be copied into the repository. Production PITR was inspected read-only;
it is currently disabled and was not reconfigured during this release.
