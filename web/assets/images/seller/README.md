# Seller decorative artwork

The approved seller screen references define these decorative assets. All UI text,
controls, tables, data and product photographs remain native or application-owned.

Built-in imagegen produced nine standalone raster assets, optimized to WebP:

- `header.webp`: cream/sage panoramic banner with a leaf-pattern weaving loom,
  terracotta pottery, green/cream yarn and white flowers; clear space at left.
- `products.webp`: woven handled basket, terracotta vase, folded botanical textile
  and olive sprigs, with clear left space and flowing sage hills.
- `inventory.webp`: yarn basket, terracotta vase, embroidered cream cloth and leaves,
  with clear left space and flowing sage hills.
- `box.webp`: open cardboard parcel containing botanical cream cloth and olive leaves;
  transparent background, no UI or text.
- `yarn.webp`: wicker basket of green yarn, knitting needles and botanical sprigs;
  transparent background, no UI or text.
- `ledger.webp`: cream spiral notepad, golden coins and olive sprigs;
  transparent background, no UI or lettering.

Each generation used its corresponding supplied reference image and required the
same warm watercolor treatment, palette and composition, without text or UI.
Additional reference assets are `orders.webp` (clipboard, package and green vase),
`settlements.webp` (tied gift and coins), and `inventory-empty.webp` (open box,
yarn and spool). Each is a transparent standalone illustration without UI text.
Source generations are retained outside the repository in the session's generated
image directory. Production images live here and do not depend on that directory.

The four SVG illustrations preserve the references' flat vector treatment for
returns, support, store preview and notifications. They contain decorative shapes
only and are rendered with empty alt text beside native headings and controls.
