# Super Admin decorative artwork

Four standalone images generated for the accepted November 2026 references:
`header.webp` (ivory marketplace banner with wicker and foliage), `package.webp`
(parcel and leaves), `access.webp` (people and account shield), and `support.webp`
(headset and conversation illustration). They contain no interface text or data.

The application supplies empty alternative text for these decorative images.
Charts, headings, tables and controls are rendered as native HTML/SVG. WebP
outputs are optimized for the embedded asset pipeline.
